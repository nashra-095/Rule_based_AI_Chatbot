# Rule-Based AI Chatbot

A simple rule-based chatbot developed in Python that responds to predefined user inputs using a dictionary-based knowledge base and conditional logic.

## Features

- Responds to greetings and common questions.
- Maintains continuous interaction using a `while` loop.
- Normalizes user input using `.strip()` and `.lower()`.
- Uses a dictionary to store predefined responses.
- Handles unknown inputs with a fallback response.
- Supports `bye` and `exit` commands.

## Technologies Used

- Python
- Dictionaries
- Conditional Statements
- While Loops
- String Handling

## Getting Started

### Prerequisites

Install Python 3 on your system.

### Installation and Execution

1. Clone this repository.
2. Open the project directory in your terminal.
3. Run the chatbot:

```bash
python chatbot.py
```

## Example Usage

```text
You: hello
PyBot: Hello! How can I help you?

You: what is ai
PyBot: AI stands for Artificial Intelligence.

You: bye
PyBot: Goodbye! Have a nice day.
```
